# Rhode Island Track Club Brand System

Internal repository for RITC brand assets, graphics, and social media templates.

## Repository Structure

```
ritc-brand/
├── assets/
│   ├── fonts/          # Vendored web fonts (56KB total)
│   ├── logo/           # Logo assets in PNG and SVG formats
│   │   ├── png/        # Transparent PNG files
│   │   └── svg/        # Vector SVG files  
│   └── photos/         # Sample race photos for testing
├── templates/          # Social media template files
├── docs/               # Brand documentation
│   └── BRAND.md        # Complete brand specifications
└── README.md           # This file
```

## Getting Started

1. **Logo Assets**: Request transparent PNG/SVG files from designer using the logo design brief
2. **Template Development**: Build six social media templates following BRAND.md specifications  
3. **Testing**: Validate templates with real race photos and various content scenarios
4. **Export**: Generate production-ready 2160x2700px files for Instagram
