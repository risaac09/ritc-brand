# RITC Logo Design Brief

## Project Overview
Create Rhode Island Track Club logo suite for digital/social media use.

## Context
Building complete brand identity for competitive running organization. Current social media templates require transparent logo assets that can overlay on race photographs.

## Brand Positioning
- **Athletic Performance**: Professional competitive running club
- **Rhode Island Identity**: Local pride without being parochial  
- **Visual Language**: Navy (#001F3F) + sand (#D2B48C), minimalist, authentic to running culture
- **Current Template Reference**: Features layered gear (sand warmups over navy singlet) with star column detail on seam

## Required Deliverables

### Primary Logo Options (propose 2-3 concepts):
1. **Wordmark**: "RHODE ISLAND TRACK CLUB" or "RITC" 
2. **Combination Mark**: Typography + graphic element
3. **Icon/Emblem**: Standalone symbol (star, track oval, running motif)

## Technical Requirements

### PNG Specifications:
- Transparent background (functional alpha channel)
- RGB color mode
- Minimum dimensions: 1000px wide for wordmarks, 500px for icons
- High resolution suitable for 2160x2700 social media exports
- Optimized file size (under 200KB per file)
- Named consistently: `ritc-logo-full.png`, `ritc-logo-abbrev.png`, `ritc-icon.png`

### SVG Specifications:
- Vector format with editable paths
- Transparent background by default
- Proper grouping and layer organization
- Clean code without unnecessary metadata
- Embedded fonts converted to outlines
- Named consistently: `ritc-logo-full.svg`, `ritc-logo-abbrev.svg`, `ritc-icon.svg`

### Color Variants (for each deliverable above):
- **Primary**: Navy (#001F3F) on transparent
- **Reverse**: White on transparent (for dark backgrounds)
- **Accent**: Sand (#D2B48C) on transparent (optional secondary use)

## Design Constraints

### Typography Direction:
- Athletic, clean, highly legible
- Avoid overly decorative or thin fonts
- Consider condensed or extended variants for different applications
- Must maintain readability at small sizes (social media thumbnails)

### Graphic Elements:
- Reference the existing "star column on seam" detail from current template
- Consider track oval, running stride, or Rhode Island geographic elements
- Maintain minimalist aesthetic - avoid complex gradients or effects
- Ensure strong silhouette recognition

### Brand Alignment:
- Professional but not corporate
- Athletic but not aggressive  
- Local (Rhode Island) but not parochial
- Performance-oriented but accessible

## Validation Requirements

### Technical Validation:
- All PNGs must have functional alpha channels (test on colored backgrounds)
- All SVGs must render correctly in modern browsers
- File sizes optimized for web delivery
- Consistent naming convention across all files

### Brand Validation:
- Works effectively overlaid on bright singlet photographs
- Maintains visibility against various background colors
- Scales appropriately from social media thumbnails to full-size posts
- Complements existing template visual language

### Integration Testing:
- Test placement in current workout announcement template
- Verify scrim overlay compatibility (logo should work with gradient overlays)
- Confirm badge positioning in 200px waistband area
- Validate against race recap template requirements

## Success Criteria

### Immediate Needs:
- Enable photo-overlay functionality in social media templates
- Replace inadequate 2020 JPG files with professional transparent assets
- Support both current workout announcement and upcoming race recap templates

### Long-term Value:
- Establish foundation for complete RITC digital brand system
- Enable consistent logo usage across all future marketing materials
- Provide scalable assets for potential merchandise or print applications
- Create professional brand presence competitive with other athletic organizations

### Quality Benchmarks:
- Logo maintains clarity when scaled to Instagram story dimensions (1080x1920)
- Works effectively over bright, saturated race photography
- Professional appearance matching caliber of competitive running organizations
- Technical reliability across all major browsers and devices
