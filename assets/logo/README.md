# Logo assets

Drop the RITC logo files here. Templates reference them by these exact names.

Expected:

- `ritc-badge.svg` or `ritc-badge.png` — the primary circular badge, navy field,
  white rope border, white anchor with the RI emblem at the crown.
- `ritc-anchor.svg` — the solid navy anchor, standalone.
- `ritc-star.svg` — the five point navy star.

## Status: not yet supplied

No logo files are in this directory. Templates render a labeled placeholder in
their place. The placeholder is obvious on purpose so nothing ships by accident.

Two official high resolution master files exist, both original to 2020 and
predating the 2026 kit refresh. They live in the club's Drive folder as JPGs:
a black and white version and a color version. JPG is the wrong format for a
badge that has to sit on a photograph, so a transparent PNG or an SVG trace is
worth asking the designer for.
